# PCB Layout

This folder contains PCB layout images and related design files for the BMS prototype.

## Contents
- Top layer PCB layout
- Bottom layer PCB layout
- 2D/3D PCB preview images
- PCB design files if available

## Design Tool
- Altium Designer

## Notes
The PCB layout was designed for a prototype BMS system using ESP32, ADS1115, MOSFET protection circuits, passive cell balancing, RS485, and CAN bus modules.
