# Schematic

This folder contains schematic files and screenshots of the BMS hardware design.

## Main Schematic Blocks
- Power supply circuit
- ESP32 central controller circuit
- Cell voltage measurement circuit
- Current measurement circuit
- Temperature sensing circuit
- Charge/discharge MOSFET protection circuit
- Passive cell balancing circuit
- LCD I2C interface
- RS485/Modbus RTU interface
- CAN bus interface using MCP2515

## Notes
The schematic was designed for a 6S2P Lithium-ion battery pack prototype.
