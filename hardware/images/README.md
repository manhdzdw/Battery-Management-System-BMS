# Hardware Images

This folder contains hardware images, PCB previews, schematic screenshots, and prototype photos of the BMS system.

## Image Categories

### 1. Schematic Screenshots
Screenshots of important hardware blocks:
- Power supply block
- ESP32 controller block
- Cell voltage measurement block
- Current measurement block
- Charge/discharge protection block
- Passive cell balancing block
- RS485 and CAN communication block

### 2. PCB Images
PCB layout and board preview images:
- Top layer
- Bottom layer
- 2D PCB layout
- 3D PCB view

### 3. Prototype Photos
Real hardware photos of the BMS prototype:
- Assembled PCB
- 6S2P battery pack
- Testing setup
- LCD display and communication modules

## Notes
These images are used to provide a quick visual overview of the hardware design and testing process.
