# Hardware Design

This folder contains hardware design files and documentation for the BMS prototype.

## Main Hardware Blocks
- Power supply block using LM2596S
- ESP32 central controller block
- Cell voltage measurement circuit using voltage dividers and ADS1115
- Current measurement circuit using a low-side shunt resistor
- Temperature monitoring circuit using NTC sensors
- Charge/discharge protection circuit using MOSFETs and optocouplers
- Passive cell balancing circuit using MOSFETs and discharge resistors
- LCD I2C display circuit
- RS485/Modbus RTU communication circuit
- CAN bus communication circuit using MCP2515

## PCB Design Tool
- Altium Designer
